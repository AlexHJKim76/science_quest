# Science Quest · 중2 과학 퀴즈

중2 과학 문제를 풀며 복습하는 웹 퀴즈 앱입니다. 단일 HTML 파일로 동작하며, 설치나 로그인이 필요 없습니다.

- 웹에서 바로 열기: https://alexhjkim76.github.io/science_quest/
- 파일: `index.html` (외부 라이브러리·네트워크 연결 없이 자체 동작)
- 문제: **2단원 × 5레벨 × 10문항 = 100문항**
  - 온몸순환과 폐순환 50문항, 우주와 우리은하 50문항
  - Lv.1 기초 개념 → Lv.2 개념 적용·비교 → Lv.3 자료·계산 추론 → Lv.4 단골 오개념 함정 → Lv.5 고난도 복합
- 레벨마다 10문제 중 8문제 이상을 맞히면 다음 레벨이 열립니다(문제 수가 바뀌면 통과 기준도 자동으로 따라갑니다).
- 틀린 문제는 ‘오답 노트’에 모여 다시 풀 수 있습니다.
- 진행 상황(푼 문제, 점수 등)은 접속한 기기 브라우저에 저장됩니다.

## 휴대폰에서 앱처럼 쓰기

- iPhone(Safari): 페이지를 연 뒤 공유 → 홈 화면에 추가
- Android(Chrome): 페이지를 연 뒤 메뉴 → 홈 화면에 추가
