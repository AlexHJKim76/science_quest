# Science Quest · 중2 과학 퀴즈

중2 과학 문제를 풀며 복습하는 웹 퀴즈 앱입니다. 단일 HTML 파일로 동작하며, 설치나 로그인이 필요 없습니다.

- 웹에서 바로 열기: https://alexhjkim76.github.io/science_quest/
- 파일: `index.html` (외부 라이브러리·네트워크 연결 없이 자체 동작)
- 문제: **2단원 × (5레벨 × 20문항 + 끝판왕 10문항) = 220문항**
  - 온몸순환과 폐순환 110문항, 우주와 우리은하 110문항
  - Lv.1 기초 개념 → Lv.2 개념 적용·비교 → Lv.3 자료·계산 추론 → Lv.4 단골 오개념 함정 → Lv.5 고난도 복합 → 👑 Lv.6 끝판왕
- **매번 새로 나옵니다**: 레벨을 시작할 때마다 그 레벨의 20문항 중 10문항을 무작위로 뽑고, ①~⑤ 보기 순서도 새로 섞습니다.
- 레벨마다 10문제 중 8문제 이상을 맞히면 다음 레벨이 열립니다.
- **👑 끝판왕**: Lv.5를 10/10 만점으로 3번 클리어하면 열립니다(단원별 만점 기록 0/3 ~ 3/3 표시). 단원마다 중2 수준에서 맞히기 힘든 복합 추론·함정 문제 10문항이 들어 있습니다.
- 문제마다 그림으로 판단하는 문항이 섞여 있습니다(심장·혈관 모식도, 혈압·혈류 속도 그래프, 기관별 혈액 분포, H-R도, 허블 법칙 그래프, 우리은하 구조도, 은하 스펙트럼). 모두 인라인 SVG라 모바일에서도 흐려지지 않고, 인터넷 없이도 보입니다.
- 틀린 문제는 ‘오답 노트’에 모여 다시 풀 수 있습니다.
- 진행 상황(연 레벨, Lv.5 만점 횟수, 오답)은 접속한 기기 브라우저에 저장됩니다. 이전 버전의 저장값도 그대로 이어집니다.
